## A7.2 LIN2 on the true dynamics at (0, 1)

`lin2_true`: for each candidate, mu_k = F(y, a_k) - g (true noiseless rollout) and J_k = the full D x D Jacobian of the
true H-step rollout wrt the start (D VJPs per candidate). Linearised outcome z_k - g ~ N(mu_k, sigma^2 J_k J_k^T) at f = 0,
so P2_k = P(|mu_k + sigma J_k w| < r), w ~ N(0, I_D): a generalised noncentral chi-square CDF at r^2. Evaluated by
M2 = 16,384 common-random-number draws of w (one fixed set shared by every candidate and start, generator seed 4242), not
by Imhof inversion; with common draws the ranking noise between candidates is far below the per-candidate SE <= 0.004.
Pick = argmax P2_k, exact ties to the smaller true distance. Also reported, not tested: `lin2` (same rule on the learned
predictor of that seed). Sets: the regenerated r2 eval sets at (0, 1), n_eval 20,000, seeds 0, 1, 2 (A6.3's sets; the
recomputed `lin1_true` and `bayes_succ` hits must equal r3's stored audit hits exactly, else void).

- **L3:** NS(lin2_true) - NS(lin1_true) >= 0.5 (NS(bayes_succ) - NS(lin1_true)) on 3/3 seeds (NS on the argmin label,
  denominator Bayes with the A6.1 tie-break, as A6.3). For scale, read before this registration: bayes_succ - lin1_true =
