**Statement.** Every prediction row of the canon is scored with exactly one token of $\{\mathrm{HOLDS},\mathrm{COUNTER},\mathrm{SPLIT},\mathrm{VOID}\}$ by the adjudicator that reads only journals (S-63): HOLDS when the deciding number lies in the prediction's region; COUNTER when it lies in the counter's; SPLIT when it lies in **any region the verse declares outside both halves** — the band between them, and, where a verse's prediction is a two-sided range, the region beyond the range's far end — scored wrong with the sign the verse prints for that region (the sign of the optimistic half where the verse names none).
