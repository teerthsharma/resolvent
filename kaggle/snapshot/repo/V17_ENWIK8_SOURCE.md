## 2. THE SLICE GUARD — `ceq.kdata.read_enwik8_slice` / `ShortRead`

The slice is now a load-bearing step of its own: a truncated mount or a
partial stream yields fewer than 100,000,000 bytes, and hashing whatever
arrived would silently pin a smaller, different object under the enwik8
name. `ceq/kdata.py` gained:

```python
class ShortRead(Exception): ...

ENWIK8_SLICE_BYTES = 100_000_000

def read_enwik8_slice(fh, n: int = ENWIK8_SLICE_BYTES) -> bytes:
    data = fh.read(n)
    if len(data) < n:
        raise ShortRead(...)
    return data
```

`build_manifest`'s enwik8 branch now opens the path and calls
`read_enwik8_slice` instead of `Path.read_bytes()`, so the same guard runs
whether it is fed a plain `enwik9` mount, an already-sliced `enwik8` file, or
(in this node's own testing) a 100 MB file extracted from the verified zip.
