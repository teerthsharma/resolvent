    SATURN holding the WATSON role, 2026-09-03, against HEAD 207e7b9 on v17k-gate0. Written without reading the other two designers' files. Evidence classes: RUN (executed this session on this box, torch 2.5.1+cu121, float64, one draw, seed 0 unless stated), READ path:line (quoted at HEAD), CITED [V] bibkey (a key in $SCRATCH/sweep/bib_*.bib whose page the owning sweep fetched), DERIVED (steps written out), DESIGN (a choice this file makes, with the MISTAKES.md mechanism it is made against).     2. The eleven rows, nine cells each#

    Conventions for every row. Bind = an identity the built arm must satisfy on the bed's real draw, with a planted mutilation battery whose every member fails at O(1), counts printed — the V15_JUPITER2_FORK.md pattern (0.9749 / 0.9165 / 1.000 / 0.4845, READ workdonenewseal.md:114-122). Control arm = the fellow approximators the arm is paired against on byte-identical draws at 4,769 matched parameters (READ CEQ_V20_R15_CONTRACT.md:119), plus the three skylines at unmatched depth/width/decode length (C2). Floor = an information floor, never floor₁ (C15, READ V20_R15_JOURNAL.md:51). Kill = a threshold frozen here. Against = the MISTAKES.md mechanism, by symbol.
